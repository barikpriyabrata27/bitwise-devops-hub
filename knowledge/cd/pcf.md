# CD: PCF

Deploying a released artifact to Pivotal/Tanzu Application Service (`cf push`
style deployment).

Demonstrated in: [bitwise-devops-pcf](https://github.com/barikpriyabrata27/bitwise-devops-pcf)

Typical shape: `cf login`, `cf push` with a manifest describing the app,
buildpack, routes, and bound services. See the repo's own README for the
exact steps.
