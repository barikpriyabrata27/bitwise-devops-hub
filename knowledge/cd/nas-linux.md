# CD: NAS (Linux)

Deploying a released artifact to a Linux-hosted NAS (e.g. Synology/QNAP or a
plain Linux box acting as a NAS).

Demonstrated in: [bitwise-devops-nasl](https://github.com/barikpriyabrata27/bitwise-devops-nasl)

Typical shape: copy the artifact via SSH/rsync, then restart the
service/container that runs it. See the repo's own README for the exact
steps.
